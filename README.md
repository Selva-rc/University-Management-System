# 🎓 University Management System

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)
![Swing](https://img.shields.io/badge/Java_Swing-007396?style=for-the-badge)

![NetBeans](https://img.shields.io/badge/Apache_NetBeans-1B6AC6?style=for-the-badge&logo=apache-netbeans-ide&logoColor=white)

A **desktop-based University Management System** developed using **Java (Swing)** and **SQL**, designed to manage academic and administrative operations through a centralized GUI application.

---

## 🚀 Features

- 🔐 **Admin Login System**
- 🎓 **Student Management** (Add / Update student details)
- 👨‍🏫 **Teacher Management**
- 💰 **Fee Management Module**
- 📝 **Examination Details Management**
- 🛠 **Utility Tools** (Notepad & Calculator)
- 🏖 **Leave Application System** (Students & Teachers)
- ℹ️ **About Page**

---

## 🛠 Tech Stack

| Technology | Usage |
|----------|-------|
| Java | Core logic |
| Java Swing | GUI |
| SQL / MySQL | Database |
| Apache NetBeans | IDE |
